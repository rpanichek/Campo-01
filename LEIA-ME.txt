RELATÓRIO DE CAMPO M3E - app de coleta de dados de topografia (PWA)  -  versão 6

O QUE FAZ
- Cada relatório tem: projeto, colaborador, tipo de levantamento, data, nome do vértice
  (obrigatório; não é repetido no novo relatório), coordenadas
  (GPS do aparelho), equipamento, altura da antena (cm), tipo de altura
  (vertical/inclinada), observações e fotos (mínimo 2).
- Projeto, colaborador, tipo de levantamento e equipamento são listas suspensas,
  com a opção "+ Adicionar novo item..." no fim de cada uma.
- Funciona sem internet depois da primeira abertura.
- Relatório salvo fica guardado no aparelho. No fim do dia, o botão Enviar
  permite escolher quais relatórios mandar (todos ou só alguns) e gerar
  um PDF por relatório ou um único PDF com todos.

FLUXO NO CAMPO
1. Preencha o relatório e toque em "Salvar relatório".
2. O botão "Novo relatório" só libera depois de salvar. O novo já vem com projeto,
   colaborador, tipo de levantamento e equipamento do anterior; o restante fica em branco.
3. Se mexer em um relatório já salvo, toque em "Salvar alterações" antes de iniciar outro.
4. Botão Enviar: o relatório atual vem marcado e aparece primeiro. Use
   "Selecionar todos" ou marque um a um. Em "Compartilhar" abre o WhatsApp/e-mail
   com os PDFs anexados; "Baixar" salva em Downloads.
5. Em Enviar também é possível editar ou excluir um relatório salvo.

LISTAS (botão "Listas" no topo)
- Importar planilha (.xlsx ou .csv) com cabeçalhos: Projeto, Colaborador,
  Tipo de Levantamento, Equipamento. Uma coluna por lista.
  "Substituir" troca a lista pelo conteúdo da planilha; "Somar" acrescenta sem repetir.
  Colunas ausentes mantêm a lista atual.
- As listas atuais aparecem só para consulta. Itens novos entram pela opção
  "+ Adicionar novo item..." no fim de cada lista suspensa.
- Exportar: baixa as listas atuais (com os itens adicionados no aparelho) no mesmo
  formato, para atualizar a planilha mestre.
- As listas ficam em cada aparelho. Para padronizar a equipe, distribua a planilha
  mestre e peça para importar.

ARQUIVOS (manter todos juntos na mesma pasta)
  index.html, jspdf.umd.min.js, xlsx.mini.min.js, manifest.webmanifest, sw.js,
  logo-m3e.png, icon-192.png, icon-512.png, icon-maskable-512.png

IMPORTANTE: GPS, modo offline e instalação só funcionam com HTTPS.
Abrir o index.html direto do celular (file://) não serve.

PUBLICAR / ATUALIZAR NO GITHUB PAGES
1. No repositório, clique em Add file > Upload files e envie TODOS os arquivos
   desta pasta, inclusive o novo logo-m3e.png. Confirme com Commit changes.
2. Aguarde 1 a 2 minutos. Nos celulares, abra o app com internet; ele baixa a
   versão nova (se ainda aparecer a antiga, feche e abra de novo).
3. Os nomes antigos nas listas (Emelid, Geodéciso) são corrigidos sozinhos para Emlid e Geodésicos.
   Os relatórios e as listas já salvos no aparelho são mantidos na atualização.

GERAR O APK (um arquivo para enviar pelo WhatsApp)
1. Com o app publicado em HTTPS, acesse pwabuilder.com, cole o endereço e clique em Start.
2. Package for stores > Android, gere o pacote e use o arquivo .apk do ZIP baixado.
3. Envie o .apk à equipe e peça para permitir instalação de fontes desconhecidas.
O APK abre o endereço publicado, então as próximas atualizações do app chegam
pelo GitHub Pages, sem gerar APK de novo.

ATENÇÃO
- Os relatórios ficam apenas no aparelho. Limpar os dados do navegador/app apaga tudo:
  envie os PDFs antes de limpar.
- Ao alterar qualquer arquivo do app, aumente a versão em sw.js
  (const VERSAO = 'm3e-relatorio-v7') para os celulares receberem a atualização.
